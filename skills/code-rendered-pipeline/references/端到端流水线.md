## 端到端命令序列

以《月球矩阵》film 工程为例（`lunar_art_remix/`），从零到飞书交付：

```bash
cd ~/.openclaw/workspace/skills/code-rendered-pipeline

# 步 1：渲染 + 装配 + BGM 混音（film 目录含 main.js / voiceover.mp3 / bgm.mp3）
python3 scripts/render_video.py --film ../../code-video-projects/lunar_art_remix
#  → output/成片.mp4（含口播 + BGM，已 verify_mix 三层验收）

# 步 2：烧字幕（srt 从 voiceover.mp3 转写，或用已有逐字时间）
python3 scripts/subtitle_pipeline.py \
    --video ../../code-video-projects/lunar_art_remix/output/成片.mp4 \
    --srt ../../code-video-projects/lunar_art_remix/口播.srt
#  → 成片_字幕版.mp4（auto 按首帧亮度猜 dark/light 样式）

# 步 3：片头片尾（独立片段拼接，时长变长）
python3 scripts/title_cards.py \
    --video 成片_字幕版.mp4 \
    --title 月球矩阵 \
    --credits 感谢收看,出品：示例团队
#  → 成片_字幕版_片头片尾版.mp4

# 步 5：飞书压缩（30MB 限内）
python3 scripts/compress.py --in 成片_字幕版_片头片尾版.mp4
#  → 成片_字幕版_片头片尾版_飞书版.mp4（≤31,457,280B）
```

**单步重跑**（改一处不用全重来）：
- 换 BGM / 调音量 → 只重跑步 1（assemble 自动重混，视频不重渲）。
- 改字幕文案 → 只重跑步 2。
- 改片头片尾文字 → 只重跑步 3。
- 只是要发飞书 → 只重跑步 5。

## 路线 B：叠加片头片尾（非默认）

仅当用户明确说「把标题叠在原视频开头画面上」「不要单独片段」时用。**默认走路线 A（独立拼接）**，更简单更标准。

叠加的核心矛盾：贴卡要重编码，但整片单遍贴卡会让 ffmpeg 在尾声被杀（产物无 moov atom，文件报废）。**必须用三段切片，禁整片单遍。**

```bash
# 1. 探关键帧定切点（K1=标题窗结束后的第一个关键帧，K2=片尾窗开始前的最后一个）
ffprobe -v error -select_streams v:0 -show_entries frame=pts_time,pict_type \
    -of csv=p=0 成片.mp4 | grep ",I"

# 2. 头段重编码贴卡（K1=8.333s 实测）
ffmpeg -y -ss 0 -t 8.333 -i 成片.mp4 -i title.png -filter_complex \
  "[1:v]loop=loop=250:size=1,fps=30,format=rgba,setpts=PTS-STARTPTS,\
   fade=t=in:st=0:d=0.8:alpha=1,fade=t=out:st=4:d=0.8:alpha=1[fg];\
   [0:v][fg]overlay=0:0:eof_action=pass[v]" \
  -map "[v]" -map 0:a -c:v libx264 -crf 21 -preset medium -c:a aac -b:a 192k head.mp4

# 3. 尾段重编码贴卡（K2=110.967s 实测，fade st 用「期望秒−K2」换算，绝不 setpts 大偏移）
ffmpeg -y -ss 110.967 -i 成片.mp4 -i credits.png -filter_complex \
  "[1:v]loop=loop=380:size=1,fps=30,format=rgba,setpts=PTS-STARTPTS,\
   fade=t=in:st=6.3:d=0.8:alpha=1,fade=t=out:st=11.5:d=1:alpha=1[fg];\
   [0:v][fg]overlay=0:0:eof_action=pass[v]" \
  -map "[v]" -map 0:a -c:v libx264 -crf 21 -preset medium -c:a aac -b:a 192k tail.mp4

# 4. 中段流复制 + concat 拼接
ffmpeg -y -ss 8.333 -to 110.967 -i 成片.mp4 -c copy middle.mp4
printf "file 'head.mp4'\nfile 'middle.mp4'\nfile 'tail.mp4'\n" > list.txt
ffmpeg -y -f concat -safe 0 -i list.txt -c copy -movflags +faststart 叠加版.mp4
```

**铁律（违则内存爆炸）**：卡片流锚在 t=0，用 `fade` 的 `st` 控制出现时刻；**绝不用 `setpts=PTS+<大秒数>/TB`** 把副流平移到后段——会让 overlay framesync 从 t=0 起为主画面帧持续缓冲等副流（1080p RGBA 8.3MB/帧 × 30fps × 上百秒 ≈ 27GB），内存耗尽被 SIGKILL，moov 永远写不上。

## 故障排查速查

| 症状 | 根因 | 解法 |
|---|---|---|
| `moov atom not found`，文件报废 | 整片单遍贴卡 / overlay 副流大偏移 | 改三段切片（路线 B 步骤），或干脆走路线 A 独立拼接 |
| 字幕烧不上 / `No such filter: 'ass'` | brew ffmpeg 无 libass | 走 `subtitle_pipeline.py`（PIL 字幕条），别试 ass/drawtext |
| 多路 overlay 卡死（CPU 100% 不动） | 全帧 PNG 当 overlay 输入 | 只画底部 1920×140 字幕条，别渲全帧 |
| "28 秒后没音乐" / BGM 半路消失 | Suno VBR 头虚报时长，BGM 提前 EOF | `assemble.true_duration` 解码重测 + `aloop` 循环铺满 |
| BGM 几乎听不见（语音段） | sidechain 过度闪避 | 改 `threshold=0.02:ratio=3`（别用 ratio≥8） |
| 片头片尾卡跟画面文字撞车 | 透明底卡叠在自带文字的场景上 | 改不透明整卡（BG #FBFBFB） |
| 抽片尾卡帧发现还是原片画面 | 拼接后时间轴变了，按旧时间抽 | 片尾卡在「原片长 + 片头长」之后，重算抽帧点 |
| 飞书报 `file exceeds limit` | 超 31,457,280B | `compress.py` 从 CRF 27 起迭代，超限 +3 |
| 渲染某段 Playwright 截图失败 | `__bootErrors` 非空 / JS 报错 | 看 `capture.mjs` 输出的 boot 错误，修 main.js |

## 脚本参数速查

### render_video.py
```
--film DIR        film 工程目录（含 main.js，可选 voiceover.mp3 / bgm.mp3）
--fps N           帧率（默认 30）
--out PATH        输出 mp4（默认 <film>/output/成片.mp4）
--no-bgm          跳过 BGM 混音（纯口播或无声片）
```

### subtitle_pipeline.py
```
--video MP4       输入成片
--srt SRT         口播字幕（SRT 格式，支持 , 或 . 毫秒分隔）
--style auto|dark|light   字幕样式（默认 auto 按首帧亮度猜）
--out PATH        默认 <video>_字幕版.mp4
```
样式：dark=白字黑边（深色画面）、light=深字白边（白板浅底）。

### title_cards.py
```
--video MP4       输入成片
--title TEXT      片头标题（一行，可空）
--credits A,B,C   片尾多行，逗号分隔（首行大字，副行小字）
--head-sec N      片头时长（默认 4）
--tail-sec N      片尾时长（默认 5）
--out PATH        默认 <video>_片头片尾版.mp4
```

### compress.py
```
--in MP4          输入成片
--crf N           起始 CRF（1080p 长片默认 27，720p 自动 -3）
--out PATH        默认 <in>_飞书版.mp4
```

### assemble.py（库，render_video 内部调用，也可独立测）
```python
from assemble import true_duration, assemble_segments, verify_mix
dur = true_duration("bgm.mp3")          # 解码重测真实时长（防 Suno 假头）
assemble_segments(seg_m4s, voice, bgm, out)   # 装配 + 混音
verify_mix(out, gaps=[21.7, 45.0])      # 三层电平验收，gaps=语音空隙时间点
```
